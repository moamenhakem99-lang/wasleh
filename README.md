# وصلة WASLA

وصلة منصة عربية RTL لتأجير الجرارات والآليات الزراعية، تربط المزارعين بأصحاب الآليات مباشرة مع بحث، تفاصيل، اتصال/واتساب، حجوزات، موافقات إدارية، وتقييمات.

## التقنية

- Next.js + TypeScript + Tailwind CSS
- REST API تحت `/api/v1`
- Prisma ORM + PostgreSQL
- JWT cookies + RBAC
- Docker Compose للتشغيل المحلي

## التشغيل المحلي

```bash
npm install
copy .env.example .env
npx prisma migrate dev
npm run seed
npm run dev
```

افتح: `http://localhost:3000`

## Docker

```bash
docker compose -p wasla up --build
```

بعد تشغيل قاعدة البيانات لأول مرة نفذ داخل الحاوية أو محليا:

```bash
npx prisma migrate deploy
npm run seed
```

## الصلاحيات

- الزائر: تصفح الآليات المعتمدة والتواصل مع أصحابها. الحجز يحتاج تسجيل الدخول.
- المزارع (`FARMER`): حجز الآليات، قراءة حجوزاته فقط، وتقييم حجزه بعد اكتماله. لا يمكنه إضافة آلية أو فتح لوحات المالك والإدارة.
- المالك (`MACHINERY_OWNER`): إضافة آلية بانتظار الموافقة، وقراءة حجوزات آلياته وإدارتها فقط.
- الإدارة (`ADMIN`, `SUPER_ADMIN`): مراجعة الآليات واعتمادها أو رفضها، والوصول إلى الحجوزات والإدارة.
- الدعم (`SUPPORT_AGENT`): لا يملك صلاحيات الإدارة أو الإضافة أو الوصول إلى الحجوزات حالياً.

مصدر قواعد الأدوار هو `lib/permissions.ts`. تتحقق الصفحات والـ API من الصلاحيات، وتتحقق عمليات الحجز أيضاً من ملكية السجل. تُقرأ صلاحية الحساب وحالته من قاعدة البيانات عند كل طلب محمي، وليس من الدور القديم المخزن في JWT.

الانتقالات المسموحة للحجز: انتظار إلى قبول أو رفض، ثم قبول إلى اكتمال. التقييم مرة واحدة فقط للمزارع صاحب الحجز المكتمل. التسجيل العام لا يقبل أدوار الإدارة أو الدعم.

للتحقق بعد تشغيل قاعدة البيانات والسيرفر:

```bash
npm test
npm run permissions:check
npm run ui:check
```

اختبار `permissions:check` ينشئ حسابات وآليات وحجوزات مؤقتة، ويفحص الطلبات المباشرة والواجهة، ثم يحذف بياناته في نهاية الاختبار. لا يعدّل حسابات التطوير.

## رفع الصور وإدارة الملاك

- إضافة الآلية تدعم رفع حتى 6 صور بصيغ JPG أو PNG أو WebP، بحد 5 MB للصورة. يمكن حذف الصورة أو اختيارها كصورة رئيسية قبل الإرسال.
- الصور غير المرسلة تُستعاد عند العودة لصفحة الإضافة، ويمكن حذفها من المعاينة. لا يتم حذف ملفات المستخدم تلقائياً.
- السيرفر يفك ترميز الصورة، يرفض الملفات غير الصالحة وSVG والصور المتحركة، ويعيد ترميزها إلى WebP بحد 1920 بكسل ويحذف بيانات EXIF، باستخدام [Sharp](https://sharp.pixelplumbing.com/api-constructor/).
- الصور غير المعتمدة متاحة لصاحب الرفع والإدارة فقط. تصبح عامة عند اعتماد الآلية، ولا يمكن لحساب إرفاق صور رفعها حساب آخر.
- التخزين محلي دائم في مجلد `uploads` خارج `public`، أو في المسار `UPLOAD_DIR`. Docker يستخدم volume باسم `wasla_uploads`. انسخ هذا المجلد احتياطياً مع قاعدة البيانات؛ النشر متعدد الخوادم يحتاج تخزيناً مشتركاً.
- `POST /api/v1/uploads`: multipart بحقل `file`. `GET /api/v1/uploads/:id` يعرض الصورة، و`DELETE` يحذف صورة غير مرتبطة بآلية يملكها الرافع.
- `POST /api/v1/admin/owners` للإدارة فقط، ويُنشئ دائماً دور `MACHINERY_OWNER` دون تغيير جلسة الأدمن. تكرار الهاتف يرجع 409.
- لوحة الإدارة في `/admin`، والملاك في `/admin/owners`، وإضافة مالك في `/admin/owners/new`، والمراجعات في `/admin/machinery` والحجوزات في `/admin/bookings`.

لترقية قاعدة البيانات ثم إضافة البيانات التجريبية الموسعة:

```bash
npm run prisma:deploy
npm run prisma:generate
npm run seed:demo
```

`seed:demo` يحتاج التصنيفات والمواقع من seed الأساسي. يضيف 6 ملاك و6 مزارعين و12 آلية و18 حجزاً و6 تقييمات، بمفاتيح ثابتة لمنع التكرار. الأسماء والهواتف والعروض تجريبية وليست سجلات حقيقية. كلمة المرور المحلية `Wasla123!`، والسكريبت يرفض العمل عند `NODE_ENV=production`.

`npm run admin:check` يفحص إنشاء مالك من الواجهة، منع الأدوار الأخرى، رفع الصور، الحذف، اختيار الغلاف، الموافقة والمعرض العام، ويختبر أحجام 320 و390 و1440 بكسل. يحذف بيانات الاختبار وملفاته في النهاية ويحفظ اللقطات في `artifacts/admin`.

## الهوية البصرية

الشعار الأصلي المستخدم هو `public/logo.png`. خط Tajawal محفوظ محليا في `public/fonts` مع ترخيصه، ويعمل دون الاتصال بخدمة خطوط خارجية. مصادر الصور موثقة في `public/images/CREDITS.md`، وصور الإعلانين التجريبيين تحمل عبارة «صورة توضيحية».
